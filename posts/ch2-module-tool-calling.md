## 为什么需要工具调用？


大模型的知识截止于训练时间，无法访问实时信息、无法执行操作。Tool Calling 让Agent突破这些限制：


- 查询实时数据（天气、股价、新闻）


- 操作外部系统（数据库、API、文件系统）


- 执行计算（数学运算、数据分析）


- 与人交互（发邮件、通知、消息推送）


## 4.1 函数调用基础


### 4.1.1 JSON Schema规范定义


每个工具必须用JSON Schema描述接口：


```
{

  "name": "get_weather",

  "description": "获取指定城市的当前天气",

  "parameters": {

    "type": "object",

    "properties": {

      "city": {

        "type": "string",

        "description": "城市名称"

      },

      "unit": {

        "type": "string",

        "enum": ["celsius", "fahrenheit"],

        "description": "温度单位"

      }

    },

    "required": ["city"]

  }

}
```


### 4.1.2 参数校验与类型约束


- 必需参数缺失 → 提示用户补充


- 类型不匹配 → 尝试转换或报错


- 枚举值非法 → 提示合法选项


- 格式错误（如日期） → 尝试解析或要求重填


### 4.1.3 调用格式纠错重试


模型生成的工具调用经常出现格式错误，需要容错机制：


1. 尝试解析JSON → 失败则提示模型重新生成


2. 参数类型不对 → 尝试自动转换


3. 工具名不存在 → 返回可用工具列表让模型重选


4. 连续失败超过阈值 → 降级为纯文本回复


## 4.2 通用内置工具


大多数Agent都应该配备的基础工具集：


| 功能 | 用途 |  |
| --- | --- | --- |
| 执行Python/JS代码 | 数学计算、数据处理 |  |
| 读写本地文件 | 配置管理、日志记录 |  |
| SQL查询 | 业务数据获取 |  |
| 搜索引擎API | 实时信息获取 |  |
| 精确数值计算 | 避免模型算术错误 |  |
| 获取当前时间 | 定时任务、时间相关推理 |  |


## 4.3 自定义业务工具


根据实际业务需求开发的专用工具：


- **第三方API对接**：微信API、钉钉API、企业内部系统


- **企业内部系统插件**：CRM、ERP、OA系统的接口封装


- **爬虫工具**：抓取特定网站的数据


- **消息推送**：邮件、短信、IM通知


- **办公工具**：日历操作、文档编辑、会议安排


## 4.4 工具编排


当任务需要调用多个工具时，编排策略至关重要：


### 4.4.1 串行调度


工具B的输入依赖工具A的输出，必须顺序执行：


```
1. search_web(query="最新Java版本") → url_list

2. fetch_page(url=url_list[0]) → page_content

3. summarize(text=page_content) → summary
```


### 4.4.2 并行调度


多个工具之间无依赖关系，可以并行执行以节省时间：


```
并行执行:

├─ get_weather(city="北京")

├─ get_stock_price(symbol="AAPL")

├─ check_calendar(user="anthony")

└─ query_database("SELECT * FROM tasks")
```


### 4.4.3 结果聚合


多个工具的结果需要合并后才能给出最终答案：


- 去重：多个来源可能有重复信息


- 排序：按相关性或时间排序


- 综合：将多个片段综合成连贯的回答


### 4.4.4 异常降级


某个工具调用失败时的应对策略：


- **重试**：瞬时错误可以重试1-3次


- **替换**：用备用工具完成相同功能


- **跳过**：非关键工具失败可以跳过，用已有信息继续


- **兜底**：所有工具都失败时，给出友好的错误提示
