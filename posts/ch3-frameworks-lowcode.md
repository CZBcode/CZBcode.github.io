## 低代码/平台化框架概览


不想写代码？低代码平台让你通过可视化界面快速搭建Agent应用。


### 3.1 Dify


- **定位**：开源LLM应用开发平台


- **核心能力**：


  - 可视化工作流编排（拖拽式）


  - 内置RAG引擎（文档上传→切片→检索→生成）


  - 支持多种模型接入（OpenAI、本地模型等）


  - 一键发布为API或Web应用


- **优势**：开源免费、功能全面、社区活跃


- **适用场景**：知识库问答、客服机器人、内部工具


### 3.2 FastGPT


- **定位**：专注于知识库问答的系统


- **核心能力**：


  - 开箱即用的RAG工作流


  - 支持多种文档格式导入


  - 对话流程可视化配置


- **优势**：上手快，专注一个场景做到极致


- **适用场景**：企业知识库、产品文档问答


### 3.3 Coze扣子


- **定位**：字节跳动出品的Bot搭建平台


- **核心能力**：


  - 丰富的预置插件（搜索、绘图、翻译等）


  - 支持发布到飞书、微信等多渠道


  - 长记忆和工作流能力


- **优势**：国内生态集成好，插件丰富


- **适用场景**：快速搭建聊天Bot、智能客服


### 3.4 FlowUs


- **定位**：类Notion + AI工作流平台


- **核心能力**：文档管理 + AI自动化工作流


- **优势**：文档和Agent一体化


- **适用场景**：知识管理 + 自动化办公


## 低代码 vs 代码级框架对比


| 低代码平台 | 代码级框架 |  |
| --- | --- | --- |
| 低（拖拽即可） | 高（需要编程） |  |
| 受限（受限于平台能力） | 极高（完全可控） |  |
| 浅（表面配置） | 深（可改底层逻辑） |  |
| 依赖平台 | 任意环境 |  |
| 产品经理、非技术人员 | 开发者、工程师 |  |
| 快（分钟级出原型） | 中等（需要写代码） |  |


## 选型建议


- **快速验证想法** → Dify / Coze


- **知识库问答** → FastGPT


- **企业级定制** → LangChain / LlamaIndex


- **多Agent协作** → CrewAI / AutoGen
