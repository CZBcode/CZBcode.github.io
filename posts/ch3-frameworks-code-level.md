## 代码级框架概览


当你需要深度定制Agent行为时，代码级框架是唯一选择。


### 4.1 LangChain


**定位**：组件化LLM应用开发框架，生态最全


**核心模块**：


- **Model I/O**：统一模型接口（OpenAI、Anthropic、本地模型等）


- **Retrieval**：RAG全流程（文档加载→切片→向量化→检索→生成）


- **Chains**：链式调用组合（将多个步骤串联）


- **Agents**：ReAct风格的Agent实现


- **Tools**：丰富的内置工具库


- **Memory**：多种记忆实现（缓冲、摘要、向量）


**优势**：社区最大、集成最多、文档完善


**劣势**：抽象层较厚、调试困难、版本迭代快导致API不稳定


**适用场景**：快速原型、需要对接多种模型和工具的项目


### 4.2 LlamaIndex


**定位**：专注于数据连接的LLM框架，长文本检索增强首选


**核心能力**：


- **数据连接器**：支持PDF、Markdown、数据库、Notion、网页等100+数据源


- **高级索引**：向量索引、关键词索引、树形索引、知识图谱索引


- **智能检索**：混合检索、路由检索、条件检索


- **后处理**：重排序、上下文压缩、引用标注


**优势**：RAG领域最强、索引策略丰富、性能优秀


**劣势**：主要聚焦RAG，通用Agent能力不如LangChain


**适用场景**：私有知识库、文档问答、企业搜索引擎


### 4.3 AutoGen（微软）


**定位**：多Agent对话协作框架


**核心能力**：


- **多Agent对话**：Agent之间通过自然语言对话协作


- **群组仿真**：模拟多人讨论的场景


- **自主沟通**：Agent自行决定和谁说话、说什么


- **人机协作**：人类可以随时介入对话


**优势**：微软背书、多Agent场景原生支持、学术研究丰富


**劣势**：学习曲线陡峭、单Agent场景偏重


**适用场景**：多角色协作、模拟讨论、复杂决策


### 4.4 CrewAI


**定位**：角色化多Agent流水线框架


**核心能力**：


- **角色定义**：为每个Agent定义角色、目标、背景故事


- **任务分配**：将复杂任务拆解并分配给不同角色的Agent


- **流程自动化**：顺序执行、并行执行、条件分支


- **工具授权**：细粒度控制每个Agent可以使用哪些工具


**优势**：直观的角色扮演模式、上手相对简单


**劣势**：生态较小、复杂场景灵活性有限


**适用场景**：内容创作流水线、代码审查、自动化报告


### 4.5 其他值得关注的框架


- **Haystack**：deepset出品，搜索增强型NLP框架


- **OpenAI Agents SDK**：OpenAI官方Agent框架，Swarm模式


- **Camel**：多角色角色扮演框架


## 框架选型决策树


1. 需要RAG/知识库？ → **LlamaIndex**


2. 需要多Agent协作？ → **CrewAI 或 AutoGen**


3. 需要快速原型/多模型切换？ → **LangChain**


4. 不想写代码？ → **Dify / Coze**


5. 需要极致性能/完全掌控？ → **直接调用LLM API**
